# Neon Bay

An open-world driving game that runs in your browser: steal a car, cruise a sunset city, lose the cops.

Play: open `index.html` through any static server, or deploy the folder to Vercel as is (no build step).

Controls: WASD / arrows to move or drive, mouse to look, E to steal or leave a car, Space handbrake, Shift run, C camera, R radio, M mute.

Missions: 8 missions from easy to hard (steal a car, 120 km/h, drifting, wanted levels, police chases).

Audio: synthwave soundtrack, engine, tyres, sirens and crashes are all synthesized with Web Audio, no audio files.
